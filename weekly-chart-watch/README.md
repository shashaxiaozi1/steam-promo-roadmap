# Steam US weekly-chart watchlist

This collection covers paid-game AppIDs on the weekly-chart shortlist without
published observations in the publisher tracker as of November 26, 2026.

Each run saves one CSV containing the observed timestamp, Japanese calendar
date, Steam AppID, advertised US storefront price and discount, and observation
status. Blank prices indicate an unavailable or unverified observation. A
403 or 429 stops that run and leaves the observations already collected.

The observable price is Steam's US app-page quote. The publisher tracker uses
prices from verified purchase packages. Keep the price sources identifiable
when joining to historical price data, especially on titles with multiple
editions. The watchlist writes its own CSVs so this provisional source never
changes publisher dashboards or their denominators.
